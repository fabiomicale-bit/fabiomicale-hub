     un'animazione con translateY minore, usare revealUp con
     CSS transform override oppure ricreate.

   @keyframes lineExtend / .animate-line-extend
     — orfani. Animazione width 0→3rem. Nessun componente attivo
     la usa.

   @keyframes float / .animate-float
     — orfani in codice attivo (solo _archive/ Hero/HeroEditorial).
     Animazione floating. Se reintrodouce floating elements,
     ricreare.

     — KEYFRAME ORFANO: nessuna classe .animate-* lo consumava.
     Nessun rimpiazzo necessario.
   ─────────────────────────────────────────────────────────────── */

  from { opacity: 0; transform: translateY(20px); }
  to { opacity: 1; transform: translateY(0); }
}

  from { width: 0; }
  to { width: 3rem; }
}

@keyframes float {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-10px); }
}

@keyframes shimmer {
  0% { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}
